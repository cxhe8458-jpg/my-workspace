# 数据建设资产库

贺程锡（禹治 · 平台部）搭建的数据生产工作资产，统一整理于此。配套台账：《数据资产总台账》。

> 资产定义：凡是会影响数据采集、解析、分类、上架、质量判断，并且后续还会重复使用的规则、Prompt、代码、配置、标准、样例和资源。

## 目录结构

| 目录 | 内容 |
|---|---|
| `skills/` | 产品抓取 Skill（company-product-scraper 唯一抓取规范 + html-param-extractor 参数还原词典） |
| `platforms/` | 三个 Web 平台：数据审核归档平台、自动化数据处理平台（清洗映射）、公司信息采集平台 |
| `scripts/` | 知网论文抓取脚本（2 个版本，油猴/篡改猴插件） |
| `docs/` | 文档模板与整理规范 |

## 平台速览

| 平台 | 说明 | 访问 |
|---|---|---|
| 数据审核归档平台 | 产品数据人工审核+归档 | 内网 192.168.2.106:8010 |
| 自动化数据处理平台 | 映射→分类+清洗→复查→id映射 一站式 | 内网 127.0.0.1:8688 |
| 公司信息采集平台 | 厂家基础信息批量抓取+审核+入库 | 内网 127.0.0.1:8000 |

## 安全说明

- 代码中已把真实 API Key 替换为占位符 `sk-YOUR_API_KEY_HERE`，部署时通过环境变量或平台配置注入。
- 各平台运行产物（`data/` 缓存、`runs/` 留档、日志）不纳入本仓库。
