# 数据审核归档平台 — 使用说明

## 登录

浏览器打开 **http://192.168.2.106:8010**（公司内网，用自己电脑就能开）
地址是 DHCP 发的、可能变；如果打不开，先找管理员要当前地址，别一直刷旧地址

- 用户名 **admin**，口令找管理员要
- 会话 12 小时后过期，过期会自动跳回登录页，重新登录即可
- 多人共用一台电脑时，用完点右上角 **⏻ 退出**

数据放在哪：

- 产品数据读 `/mnt/d/公司数据自动化检验平台/公司数据`，**不复制、不搬动**
- 审核状态存在服务器的 `~/.local/share/审核归档平台/`
- 归档目标默认 `/mnt/d/已审核数据`，在归档页可改

⚠ **两条纪律**：

1. **一家公司同时只让一个人处理**。两个人同时开同一家，一方点归档会把整个文件夹
   移走，另一方正在改的图片/PDF 就会操作失败。
2. 大家共用 admin 一个账号，**审核历史记不出是谁改的**，动手前想清楚。

⚠ **旧平台请停用**。两个平台同时跑会往同一份产品数据里各写各的。

## 一、产品审核

### 公司列表

公司按阶段分四组：**未审核 / 审核中 / 可归档 / 已归档**。卡片显示产品总数、
通过与有问题的条数、覆盖率，以及**缺 HTML 的数量**。

组内次序：「审核中」按覆盖率从高到低（快检完的排最前）；**「已归档」按归档时间倒序**，
刚归档的排在最前面，卡片上写明归档时间与去向，不用在一长串公司名里翻找。
归档页的公司卡片同样按这个次序排。

### 逐个审核

点公司进入，左侧是分类树（灰点=未检，绿=通过，红=有问题，`无H`=缺网页源文件），
右侧依次展示：

| 面板 | 看什么 |
|---|---|
| 产品信息 | `info.json` 里参数、图片、PDF、URL 之外的**全部字段**：产品描述、产品特性/特点/特征、产品应用、所属大类、二级分类、主图URL…… 重点核对描述与应用是否张冠李戴、有无截断、有没有混进别的产品或整站通用的宣传文案 |
| 参数信息 | 五种形态自动适配：扁平键值 / 多型号或分组子表 / **记录式（每条参数一条记录，含 名称·符号·值·单位·条件 六列表）** / 纯参数图 / 空。子表或多型号多时上方有跳转按钮，可全部收起。**点任意一行**打勾标记「已核对」——纯浏览辅助，切换产品即重置，不写入数据 |
| 主图 / 参数图 | 点图看大图；可上传、替换、删除、改归类 |
| PDF 说明书 | 内嵌预览；可上传、替换、删除 |
| 网页源文件 | 自动检测目录里有没有 `.html`，✓/✗ 徽标同时显示在标题和左侧树上。**仅作提示，不影响标记与归档** |

**「产品信息」面板的三条阅读约定**：

- **字段是兜底展示的**——凡是没在其他面板露过面的键都会列出来，
  以后爬虫新增字段不用改平台代码也能看见，不会有"采了却没人看见"的字段
- **「字段存在但为空」会标黄**，与「info.json 里压根没有这个键」分开提示：
  前者多半是官网确实没写，后者往往是解析器漏了一整段，两种情况的处理方式不一样
- 长描述默认折叠，点「展开全文」看完整内容；折叠**只是视觉上的**，不会截断数据。
  用「；」或换行串起来的多条特性/应用会自动拆成条目，方便逐条对照官网

底部标记栏常驻视口底边（参数再长也不必滚回顶部）：

- **✔ 通过**（快捷键 `A`）
- **✘ 有问题**（快捷键 `D`）→ 展开说明框，**必须写清问题在哪**才能提交；说明会记入审核历史，并显示在产品页顶部

标记后自动跳到下一个未检产品。

### 一键通过

公司工作区顶部「✔ 一键通过」：把该公司**所有未检产品**一次性标为通过。

- 已标「有问题」的**不受影响**，仍需逐个处理
- 二次确认会写明将影响几个产品
- 每个产品都写一条审核历史，可追溯

### 数据修正

- **上传图片**：面板右上「＋上传」，或在产品页**直接 Ctrl+V 粘贴**（不必先点上传），
  粘完选「存为主图」还是「存为参数图」，可连续粘多张。同一张图重复粘贴自动去重。
  任何格式都会自动转 PNG 并按 `主图.png / 参数图_N.png` 规范命名（透明通道保留，不拍平白底）
- **改归类（主图 ↔ 参数图）**：两种改法——①点图片下方「→参数图 / →主图」按钮，
  不受滚动位置影响，推荐；②把图拖到另一个面板的**任意位置**（含标题栏），
  拖到屏幕上下边缘会自动滚动。松手时不在面板内会提示，不会静默失败
- **PDF**：上传 / 替换 / 删除
- **改 URL**：产品名旁 ✏️ 改页面URL，PDF 面板 ✏️ 改手册URL
- **删除误提取产品**：整个文件夹移入备份区，左下角 20 秒内可撤销
- **新增产品**：补录漏提取的产品，建骨架后用上传功能补齐

所有修改前原文件自动备份到 `~/.local/share/审核归档平台/backups/`，操作记入产品历史。

> **报错时请先看面板再决定**：任何写操作报错后，平台会自动回查磁盘真实状态并刷新面板。
> 先核对是否其实已经生效，**不要直接重试**——重试会产生重复数据。
> 报错提示写的是真实原因，完整堆栈在 `~/.local/share/审核归档平台/errors.log`。

### 对比模式（`W`）

左边产品数据，右边官网原页，点 ▶ 打开。两种方式：

- **并排窗口**（默认）：打开一个窗口停靠右半屏，平台自动压缩到左半屏。
  浮动条常驻「▶ 打开产品页 / 🔁 跟随 / 🔝 官网置顶 / ⛶ 切回全宽 / ✕ 关闭」，按住空白处可拖动
- **页内内嵌**：嵌在页面里。部分网站拒绝内嵌，点「代理」由平台代抓展示

**🔁 跟随（默认开启）**：切换产品时对比窗口自动换到该产品的网页，不用每次点 ▶。
关掉它就回到手动模式——切产品后窗口停在上一个产品，浮动条高亮提示
「⚠ 对比窗口还停在上一个产品，点 ▶ 切到当前产品」。整个对比结束点 ✕，窗口一并关掉。

**有些官网（发 COOP 响应头，如 hr-eo.com）禁止别的页面操作自己的窗口**：那种窗口平台
既关不掉、也换不了页，只能一个产品攒一个。平台会提前探测并对这类站点改开
**平台自己的对比窗口**——顶栏写着产品名，官网内嵌在里面；官网连内嵌也禁止时自动切成
「代理渲染」（平台代抓页面，文字与参数表忠实，交互脚本可能失效）。顶栏按钮：
「代理渲染/改直连」切换取页方式、「⟳」重载、「↗ 原窗口」用浏览器新窗口打开真页面
（那个窗口平台管不了，要自己关）。

> 若曾经开出过关不掉的官网窗口，平台会提示「请手动关闭」，并把该域名记下来，
> 下次点 ▶ 自动换成可控窗口，不会再继续攒。

点平台的按钮/图片/表格时**不会**抢走焦点，所以拖拽、`Ctrl+V`、快捷键都能正常用；
需要把官网调到最前面时点 🔝。

### 快捷键（按 `?` 查看）

`A` 通过 · `D` 有问题 · `J`/`K` 上下个产品 · `N` 下一个未检 · `W` 对比模式 ·
`E` 参数子表全展开/收起 · `Esc` 关闭 · `Ctrl+V` 粘贴图片

## 二、归档

**门槛：公司下所有产品必须都是「通过」**。不达标的卡片会写明「还有 N 个未检 / M 个有问题」
并给出「去处理 →」按钮，直接跳到审核页的第一个问题产品。

达标的公司勾选「选中归档」→ 顶部填归档路径 → **📦 归档选中公司**。二次确认会列出
公司名单和目标路径。

- 归档 = 把**整个公司文件夹移动**到归档路径，源目录清空
- 审核记录原地保留，可追溯
- 已归档公司仍可**只读复查**，一切修改被拦下
- **↩ 撤回归档**：把文件夹搬回来并从台账移除，这是修改已归档数据的唯一正规入口

#### 归档结果里出现 ⚠ 提示时

归档成功但带一句 ⚠，说明**数据已经归档到位**，只是有件小事要你知道：

- **「源目录只剩空目录未能删除」** —— 文件都搬走了，但源目录的空壳被 Windows 占住删不掉
  （资源管理器开着那个目录、或杀毒软件正在扫都会这样）。归档本身是有效的，
  这个空壳你随手删掉即可，不删也不影响。
- **「上一次归档只差最后一步，已补完」** —— 说明上回归档搬到一半被打断了：
  数据其实已经进了归档区，但台账没写上，于是这家公司卡在"既不在库内也不在已归档"的
  中间态。这次点归档把它补完了，不用做别的。

只有当提示写的是**「源目录仍有文件未能删除」**时才需要你介入：
两边都有文件，得你自己核对后决定删哪份，平台不会替你猜。

### 归档台账

记录每次归档的公司、产品数、时间、去向，**按归档时间倒序排列**（从旧平台迁移进来的
历史条目也一并归入这个次序，没有时间戳的排在最后），并实时校验：

- **正常** — 目标目录在
- **目录已不在原处** — 被下游流程搬走或改名了，记录保留但点不开
- **⚠ 库内又有同名文件夹** — 两份数据各自漂移，需要你决定留哪份

## 三、版本提示横幅

页面顶部若出现红色横幅，它会写清是哪一边旧了：

- **后端跑的是旧版本代码** → 终端 Ctrl+C 后重新 `python3 run.py`
- **浏览器用的是缓存里的旧前端** → 重启服务没用，按 Ctrl+F5
- **连不上后端服务** → 确认服务在运行

横幅每 3 秒自动复查，**修好后会自己消失**，不用刷新页面。
